# Privacy Policy – ​​Depremci Earthquake Reporter

**Last updated:** 17.05.2026

The Earthquake Reporter application values ​​user privacy. This Privacy Policy has been prepared to explain what data the Earthquake Reporter application processes, for what purposes it uses this data, and how user data is protected.

## 1. Data Controller
The application publisher is responsible for data processing activities related to the Earthquake Reporter application.

**Publisher:** Yuksel Acikgoz

**Application name:** Depremci

## 2. Data Processed
The Earthquake Reporter may process the following limited data to enable the application to perform its basic functions:

- settings defined by the user within the application,
- user interface preferences,
- technical log records related to the application's operating status,
- approximate or precise location information if permitted by the user,
- in-app parameters required for filtering earthquake data and calculating events near the user.

## 3. Location Data
EarthquakeAlert may use location information if permitted by the user.

Location information is processed only for the following purposes:

- to identify earthquake events near the user,
- to provide distance-based earthquake notifications,
- to operate in-app filtering and prioritization features.

Location data will not be used without the user's explicit permission or system-level permission preference.

## 4. Purpose of Data Use
Data processed by EarthquakeAlert is used only for the following purposes:

- to provide the basic functions of the application,
- to maintain user preferences,
- to filter earthquake data according to user preferences,
- to execute notification and system tray functions,
- to detect application errors, enhance security, and improve stability.

## 5. Data Storage
EarthquakeAlert may store user settings and some technical data necessary for the operation of the application locally on the user's device.

This data is retained to ensure application functionality and is processed to a minimum extent possible.

## 6. Sharing Data
Depremci does not sell, rent, or share user personal data with third parties for advertising/marketing purposes.

Data may only interact with third-party services in the following limited circumstances:

- data sources used to obtain earthquake data,
- system or platform components used by the application,
- situations where legal obligations must be fulfilled.

## 7. Third-Party Data Sources
Depremci may obtain earthquake data from third-party publicly available or authorized data sources.

The accuracy, timeliness, and continuity of the data provided by these sources are the responsibility of the respective data providers.

## 8. Logs and Technical Data
The application may generate limited technical logs for debugging, security, performance monitoring, and stability purposes.

These logs are used, as far as possible, only for technical diagnostic purposes.

## 9. Children's Privacy
Depremci is not specifically designed to collect data from children.

The application is intended for general use and does not knowingly conduct any special data collection activities targeting children.

## 10. Security
Depremci implements reasonable technical and organizational measures to ensure the security of processed data.

However, there is no absolute guarantee of security for data transmission over the internet or electronic storage methods.

## 11. User Preferences and Rights
Users can:

- manage application permissions from operating system settings,
- turn location access on and off at any time,
- disable application data stored locally on the device by uninstalling the application.

Some locally stored data may be deleted by uninstalling the application or clearing it by the user.

## 12. Changes to the Privacy Policy
This Privacy Policy may be updated from time to time.

The current version is provided with the latest publication date. Continued use of the application means acceptance of the current Privacy Policy.

## 13. Third-Party Services
The application obtains earthquake data from the following publicly available APIs:

- AFAD (Disaster and Emergency Management Presidency)
- Kandilli Observatory
- EMSC (European-Mediterranean Seismological Centre)
- USGS (U.S. Geological Survey)
- FDSN (International Federation of Digital Seismograph Networks)

## 14. Contact
For questions, requests, or notifications regarding privacy, please contact the application publisher.

**Publisher:** Yuksel Acikgoz (yukselacikgoz@hotmail.com)




# Gizlilik İlkesi – Depremci Deprem Bildirimcisi

## 1. Veri sorumlusu
Depremci uygulamasına ilişkin veri işleme faaliyetlerinden uygulama yayıncısı sorumludur.

**Yayıncı:** Yuksel Acikgoz  
**Uygulama adı:** Depremci

## 2. İşlenen veriler
Depremci, uygulamanın temel işlevlerini yerine getirebilmesi için aşağıdaki sınırlı verileri işleyebilir:

- kullanıcı tarafından uygulama içinde belirlenen ayarlar,
- kullanıcı arayüzü tercihleri,
- uygulama çalışma durumu ile ilgili teknik günlük (log) kayıtları,
- kullanıcı tarafından izin verilmesi halinde yaklaşık veya kesin konum bilgisi,
- deprem verilerinin filtrelenmesi ve kullanıcıya yakın olayların hesaplanması için gereken uygulama içi parametreler.

## 3. Konum verisi
Depremci, kullanıcı tarafından izin verilmesi halinde konum bilgisini kullanabilir.  
Konum bilgisi yalnızca aşağıdaki amaçlarla işlenir:

- kullanıcıya yakın deprem olaylarını belirlemek,
- mesafe bazlı deprem bildirimleri sunmak,
- uygulama içi filtreleme ve önceliklendirme özelliklerini çalıştırmak.

Konum verisi, kullanıcının açık izni veya sistem düzeyindeki izin tercihi olmaksızın kullanılmaz.

## 4. Verilerin kullanım amacı
Depremci tarafından işlenen veriler yalnızca aşağıdaki amaçlarla kullanılır:

- uygulamanın temel işlevlerini sağlamak,
- kullanıcı tercihlerini korumak,
- deprem verilerini kullanıcı tercihlerine göre filtrelemek,
- bildirim ve sistem tepsisi işlevlerini yürütmek,
- uygulama hatalarını tespit etmek, güvenliği artırmak ve kararlılığı iyileştirmek.

## 5. Verilerin saklanması
Depremci, kullanıcı ayarları ve uygulamanın çalışması için gerekli bazı teknik verileri kullanıcının cihazında yerel olarak saklayabilir.  
Bu veriler, uygulama işlevselliğini sağlamak amacıyla tutulur ve mümkün olan ölçüde asgari seviyede işlenir.

## 6. Verilerin paylaşılması

Veriler, yalnızca aşağıdaki hallerde sınırlı olarak üçüncü taraf hizmetlerle etkileşime girebilir:

- deprem verilerinin alınması için kullanılan veri kaynakları,
- uygulama tarafından kullanılan sistem veya platform bileşenleri,
